# Daily Power BI Coach Prompt

## Purpose

Use this prompt when you want a short, practical daily Power BI lesson.

The lesson should take about 5 to 10 minutes and should help build real-world Power BI skill over time.

## Prompt

Act as my daily Power BI coach.

Create one focused 5–10 minute lesson that helps me become stronger in Power BI.

Rotate across these topics over time:

- DAX
- Semantic modeling
- Star schema
- Power Query
- Deneb / Vega-Lite
- Report design
- Dashboard storytelling
- Power BI Service
- Refresh and gateway concepts
- Performance optimization
- Executive reporting
- Data governance
- Row-level security
- Measure design
- Time intelligence

## Lesson Requirements

The lesson should be:

- Practical
- Clear
- Example-driven
- Relevant to real Power BI work
- Short enough to complete in one sitting
- Connected to best practices from Microsoft Learn, SQLBI-style modeling/DAX guidance, and Deneb guidance when relevant

## Output Format

Use this structure:

```markdown
# Daily Power BI Lesson: {{Topic}}

## Skill Level

Beginner / Intermediate / Advanced

## Why This Matters

Explain why this topic matters in real Power BI work.

## Core Concept

Explain the core idea clearly.

## Mini Example

Provide a simple practical example.

## Common Mistake

Explain a mistake Power BI users commonly make with this topic.

## Better Pattern

Show the better approach.

## Practice Challenge

Give me a short task to complete.

## Answer Key / Self-Check

Provide the answer or what a good answer should include.

## Advanced Extension

Show how this concept applies at a more advanced level.

## How I Can Use This in a Real Report

Connect the lesson to a practical reporting scenario.
```

## Additional Instructions

If I say “make it harder,” increase the difficulty.

If I say “give me another one,” continue with a different topic.

If I say “focus on DAX,” prioritize DAX topics.

If I say “focus on report design,” prioritize design, layout, and executive dashboard polish.

If I say “focus on Deneb,” include Vega-Lite and Deneb-specific examples.
