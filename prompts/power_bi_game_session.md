# Power BI Game Session Prompt

## Purpose

Use this prompt to run an interactive Power BI learning game with levels, scoring, and practical business scenarios.

## Prompt

Run an interactive Power BI learning game.

The purpose is to help me improve Power BI through practical challenges, not trivia.

## Game Rules

- Give me one challenge at a time.
- Do not give the answer until I respond.
- Score my answer from 0 to 10.
- Explain what I got right.
- Explain what I missed.
- Give the stronger answer.
- Track my skill progress.
- Offer the next challenge.

## Game Levels

Use these levels:

1. Beginner Analyst
2. Report Builder
3. DAX Apprentice
4. Model Designer
5. Semantic Model Architect
6. DAX Strategist
7. Deneb Visual Designer
8. Executive BI Consultant
9. Performance Optimizer
10. Power BI Master

## Skill Categories

Track these skills:

- DAX
- Semantic modeling
- Star schema design
- Power Query
- Deneb / Vega-Lite
- Report design
- Performance optimization
- Power BI Service
- Business interpretation
- Executive communication

## Challenge Types

Use a mix of:

- Multiple choice
- Short answer
- Fix the DAX
- Identify the grain
- Design the star schema
- Choose the correct visual
- Critique a dashboard
- Diagnose model behavior
- Explain filter context
- Create a Power Query strategy
- Map fields for Deneb
- Improve an executive report

## Start Format

Use this structure to start each challenge:

```markdown
# Power BI Game: Level {{Level Number}} - {{Level Name}}

## Skill Focus

## Scenario

## Dataset / Model

## Challenge

## Your Task

## Scoring Rubric

Reply with your answer, and I will score it from 0 to 10.
```

## After I Answer

Use this structure:

```markdown
## Score

## What You Got Right

## What Needs Work

## Stronger Answer

## Why This Matters

## Skill Progress

## Skill Unlocked

## Next Challenge Options
```

## Scoring Rules

Use this scale:

```text
0-2 = Incorrect or unsafe approach
3-4 = Partially correct but misses key concept
5-6 = Acceptable but incomplete
7-8 = Strong practical answer
9-10 = Production-quality, senior-level answer
```

## Starting Instruction

Start at Level 1 or Level 2 unless I request advanced mode.

If I say “advanced mode,” start at Level 5 or above.

If I say “DAX mode,” focus on DAX.

If I say “modeling mode,” focus on semantic model and star schema.

If I say “Deneb mode,” focus on Vega-Lite and custom visuals.

If I say “executive mode,” focus on report design and dashboard critique.
